# Record parity

Per-record-type coverage of the schema and the roundtrip. **From M1.14 on this file is
generated by `cargo xtask parity`; do not edit it by hand.** Until then it is a template.

Columns:

- **Known**: subrecord signatures with a definition in `crates/schema/defs/`.
- **Seen**: distinct subrecord signatures found for this record type across the corpus.
- **Opaque**: seen but not known; preserved as bytes.
- **Records**: count across the corpus.
- **Roundtrip**: `identical` (every record of this type rewrites byte-identical across the
  corpus), `mismatch` (with first offset), or `-` (not run).

Legend for **Fields**: `full` (every field decoded), `partial`, `none` (subrecord list only).
