# Docs index

What each doc tree is for, which files code reads, which are generated and which are history.
Agents: read this page, not the whole tree. Most files here are long; open only the one your
task names.

Roles used below:

- **product**: for a KitKraft user; some are named in command output.
- **reference**: for contributors; read when your task touches the area.
- **checked**: code or a test reads the file. Moving it, renaming a heading or dropping a row
  fails `cargo xtask ci` or changes runtime behaviour.
- **generated**: written by a tool; never edit by hand, rerun the tool.
- **process**: agent workflow state (tickets, status, plans).
- **history**: dated snapshots; kept for provenance, not current.
